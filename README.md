📝 Python To-Do List Application

A simple, lightweight, and efficient command-line To-Do List application written in pure Python. This project requires no external libraries or complex installations, making it an ideal starter project for beginners looking to learn core programming concepts like file handling, loops, lists, and error management.

✨ Features

View Tasks: Displays all your current pending tasks neatly numbered in a list.

Add Tasks: Allows you to quickly add new tasks to your active list.

Delete Tasks: Remove completed tasks by selecting their corresponding number.

Persistent Storage: Automatically saves your tasks to a local text file (todo_list.txt) so they remain safe even after you close the application.

Error Handling: Built-in validation to prevent program crashes if invalid inputs or numbers are entered.

🛠️ Prerequisites

To run this application, you only need:

Python 3.x installed on your computer. (No external pip packages required!)

🚀 Getting Started & Installation

Clone or Download the Repository:
Save the Python script as todo.py in a folder on your computer.

Open a Terminal / Command Prompt:
Navigate to the folder where you saved your todo.py file.

Run the Script:
Execute the following command in your terminal:

python todo.py


📖 How to Use

When you run the script, you will see an interactive menu in your terminal:

=== TO-DO LIST APP ===
1. View Tasks
2. Add Task
3. Delete Task
4. Exit
Choose an option (1-4): 


Type 1 to see your current list of tasks.

Type 2 to add a new task when prompted.

Type 3 and enter the task number to delete a finished item.

Type 4 to exit the program safely.

📂 Project Structure

├── todo.py          # Main application script
└── todo_list.txt    # Automatically generated file that stores your tasks locally
